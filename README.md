## Development

Built with [Jaspr](https://jaspr.site) (static mode).

```sh
dart pub get
jaspr serve   # dev server on http://localhost:8080
jaspr build   # static output in build/jaspr
```

Pushes to `main` are deployed to GitHub Pages by `.github/workflows/main.yml`.
